# 고시원 수익률 자동 분석기

방개수·보증금·권리금·방별임대료를 넣으면 월 순수익·연 수익률·원금 회수기간을 즉시 계산하는 단일 페이지 웹앱.
주소를 넣으면 그 위치 기준으로 주변 고시원 시세·재개발/재건축 정보를 외부 지도·포털에서 바로 열 수 있음.

- 프레임워크·빌드·백엔드·외부 API 키 없음. `index.html` 하나.
- 매물 여러 개 저장/불러오기는 브라우저 `localStorage` (기기별 로컬, 동기화 아님).
- 계산 로직은 원본 엑셀(`고시원임장보고서`)과 대조 검증됨. `HANDOFF.md` 참고.

## 로컬 실행

```
python -m http.server 8777
# http://localhost:8777/index.html
```

또는 `index.html` 을 브라우저로 바로 열어도 됨(외부 링크는 새 탭으로 열림).

## 주변 정보 링크

주소를 입력하면 활성화되는 버튼들:

| 버튼 | 여는 곳 |
|---|---|
| 주변 고시원·원룸텔 시세 | 네이버 지도 `{주소} 고시원` 검색 |
| 내 주소 위치 지도에 표시 | 네이버 지도 (주소에 핀) |
| 주변 재개발·재건축 조합 | 카카오맵 `{주소} 재개발정비사업조합` 검색 |
| 서울 재개발·재건축 공식 현황 | 정비사업 정보몽땅 (주소 자동이동 X, 자치구 직접 선택) |

고시원 **방값(월세)** 은 지도 링크로 이동해 각 매물에서 확인. 재개발 **공식 구역·단계**는
정비사업 정보몽땅(서울)에서 확인. 전국 재개발 구역의 무료·무키 공개 API는 없음(서울시 OA-2253 2026.08.30 종료).
